# 🆘 Support

## Before requesting help

1. Read the [README](README.md).
2. Review the [FAQ](docs/faq.md).
3. Follow the [installation guide](docs/installation.md).
4. Check the browser console and Network panel for the affected page.

## Include in a useful report

- Affected page: home, about, or media.
- Browser and operating system.
- Screen size or viewport dimensions.
- Steps to reproduce.
- Expected and observed behaviour.
- Sanitized browser console errors.
- Whether the issue affects a local server or deployed site.

## Do not include

- Private contact information.
- Credentials or tokens.
- Private user data.
- Copyrighted artwork or other files you do not have permission to share.
- Full browser exports that contain session cookies.

## External resources

Bootstrap, jQuery, icon/font services, and the Elfsight widget are external dependencies. Their outages or policy changes can affect the site independently of the local repository.

Security issues should be reported privately using [SECURITY.md](SECURITY.md).
