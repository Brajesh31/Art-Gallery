# ♿ Accessibility statement

## Scope
Art Gallery is a static HTML/CSS site with a client-side carousel and external resources. Accessibility depends on page markup, browser, operating system, third-party scripts, and assistive technology. This document is a review standard, not proof of formal WCAG conformance.

## Expectations
- Pages use semantic landmarks and logical heading structure.
- Navigation is keyboard operable with visible focus.
- Informative images have meaningful alternative text.
- Colour is not the only way to convey information.
- Text and controls remain usable at 200% zoom.
- Layout adapts to smaller viewports without hiding essential content.
- Carousel interaction does not require a mouse or rely only on motion.
- Reduced-motion preferences are considered.
- Third-party widgets do not trap keyboard focus.

## Known gaps
The current HTML image elements need alt-text review. Placeholder search controls and social links should be removed or made meaningful. The Flipster carousel and Elfsight widget need browser and assistive-technology testing.

## Reporting an issue
Include the affected page, browser, assistive technology if applicable, viewport, steps, and expected behaviour. Do not include personal data or assets you do not have rights to share.
