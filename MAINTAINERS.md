# 👥 Maintainers

## Current maintainer

## Responsibilities
The maintainer keeps the published site and repository documentation accurate, reviews dependency and image-licensing changes, handles security reports, and ensures that user-visible claims reflect working functionality.

## Requesting review
Open a focused pull request with a problem statement, scope, screenshots when useful, and browser validation evidence. Discuss architectural changes in an issue first. Use the private reporting route in [SECURITY.md](SECURITY.md) for vulnerabilities.

This file describes repository responsibilities. It does not imply guaranteed response times or continuous support.
