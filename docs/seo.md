# 🔎 Search engine optimization

## Current SEO scope

The project is a small static multi-page site. Search visibility depends on meaningful page titles, descriptions, headings, semantic HTML, crawlable links, image metadata, canonical URLs, and hosting configuration.

Do not claim ranking, traffic, indexing, or structured-data benefits without measurement.

## Page-level checklist

- [ ] Each page has a unique descriptive title.
- [ ] Each page has a concise meta description.
- [ ] Each page has a meaningful primary heading.
- [ ] Navigation links use real destinations.
- [ ] Informative images have descriptive alt text.
- [ ] The site is available over HTTPS.
- [ ] Canonical URLs are correct if multiple hostnames serve the same content.
- [ ] A sitemap is added only after the final public domain is known.
- [ ] robots.txt does not accidentally block public pages.
- [ ] Social preview metadata is accurate and points to real assets.

## Image search

Use accurate alt text and filenames that describe the image without keyword stuffing. Record creator and licensing details separately. Do not infer artist names or artwork titles from filenames such as `img1.jpg`.

## Structured data

Do not add generic Product, Organization, or ArtGallery structured data unless the site actually meets the schema meaning and all values can be verified. Incorrect structured data can mislead crawlers.

## Search functionality versus SEO

The visible search form is not a functioning site search feature. Search engine optimization does not make that form work. Implementing site search would require a real index and user-facing behaviour.

## Measurement

Use a verified Search Console property and privacy-reviewed analytics only if needed. Record crawl/indexing evidence and dates. Avoid publishing private account identifiers or analytics credentials.
