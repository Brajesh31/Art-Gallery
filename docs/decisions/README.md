# 🧠 Architecture decision records

Architecture Decision Records (ADRs) preserve the reasoning behind meaningful technical choices. They describe the decision at the time it was made and should be updated only when the decision is superseded or materially changes.

## Index

| ADR | Decision | Status |
|---|---|---|
| [0001](0001-static-site-architecture.md) | Keep the site static | Accepted |
| [0002](0002-flipster-carousel.md) | Retain the existing Flipster carousel for now | Accepted, reviewable |
| [0003](0003-local-artwork-assets.md) | Keep artwork as local static assets | Accepted, reviewable |

Use the [ADR template](../templates/architecture-decision-record.md). Include context, options, decision, consequences, security/accessibility implications, and evidence. Do not record an unverified assumption as a fact.
