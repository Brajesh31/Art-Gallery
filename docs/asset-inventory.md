## Metadata still to verify

For every original artwork, record the verified title, creator, source URL, license/permission, attribution wording, pixel dimensions, alt text, and any applicable model/property release. The current filenames do not establish those facts.

## Asset change checklist

- [ ] Source and rights verified.
- [ ] File format and dimensions recorded.
- [ ] File size optimized for intended display.
- [ ] EXIF metadata reviewed.
- [ ] Alternative text written from the actual visual.
- [ ] HTML/CSS reference updated.
- [ ] Local asset validation passes.
- [ ] Visual layout checked on desktop and mobile.
