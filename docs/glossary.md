# 📖 Project glossary

| Term | Meaning in this repository |
|---|---|
| Static site | Website served as files without a project-owned application server |
| HTML | Markup defining page content and structure |
| CSS | Stylesheet language controlling layout and visual presentation |
| Carousel | Interactive presentation that cycles or positions a set of images |
| Flipster | jQuery carousel plugin used on the home page |
| CDN | Content Delivery Network serving external libraries or assets |
| Bootstrap | CSS/JavaScript framework used for navigation and layout utilities |
| jQuery | JavaScript library required by the local Flipster plugin |
| Elfsight | Third-party widget platform referenced on the media page |
| Relative path | Resource path resolved relative to the current document or stylesheet |
| Mixed content | An HTTPS page requesting an insecure HTTP resource |
| SRI | Subresource Integrity, a browser mechanism for checking fetched resource bytes |
| CSP | Content Security Policy, a browser security policy restricting allowed resource origins |
| Alt text | Text alternative for an image |
| EXIF | Metadata that may be embedded in image files |
| LCP | Largest Contentful Paint, a Core Web Vital measuring main content render time |
| CLS | Cumulative Layout Shift, a Core Web Vital measuring unexpected layout movement |
| INP | Interaction to Next Paint, a Core Web Vital measuring interaction responsiveness |
| ADR | Architecture Decision Record documenting an important technical decision |
| CI | Continuous Integration, automated checks run on repository changes |
| Static hosting | Hosting that serves files directly without application-side rendering |
| Widget | An embedded third-party component rendered within a page |
| Asset provenance | Evidence of where an image or other media originated and who owns it |
