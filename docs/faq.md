# FAQ

## Does this project need Node.js?

No. It is plain HTML, CSS, and JavaScript; a browser or simple static server is sufficient.

## Does it have a backend?

No. There are no APIs, authentication flows, user accounts, or database operations.

## Can it be deployed to GitHub Pages?

Yes. Publish the repository root as a static site and ensure the configured entry page is `index.html`.

## Where are images stored?

The gallery assets are under `images/`. Confirm their usage rights before redistribution.
