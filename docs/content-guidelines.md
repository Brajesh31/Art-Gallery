# ✍️ Content and editorial guidelines

## Accuracy
- Describe only features that exist in the current repository.
- Mark proposed capabilities as proposed.
- Do not invent artist names, artwork titles, sources, or historical context.
- Do not claim a live demo, accessibility conformance, or browser support without evidence.
- Keep page labels and navigation names consistent.

## Artwork descriptions
Write alternative text based on visible content. Keep it concise and useful. Do not guess a person's identity, location, or other attributes. Do not use keyword stuffing.

## Documentation style
- Use clear headings and concise paragraphs.
- Prefer tables for comparisons and inventories.
- Use Mermaid for editable technical diagrams.
- Add emojis to improve scanning, not to decorate every sentence.
- Use badges only when their target and meaning are real.
- Keep relative links accurate and test them.
- Explain technical acronyms on first use.

## Change review
Review text for spelling, broken links, outdated screenshots, unverified claims, and contradictions with the actual HTML/CSS/JavaScript before merging.
