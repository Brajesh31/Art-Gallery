# 🎨 Visual assets

This directory contains project-authored SVG visuals used in the README and technical documentation.

| File | Purpose | Embedded in |
|---|---|---|
| `art-gallery-banner.svg` | Project identity banner | Root README |
| `architecture-overview.svg` | Static page and dependency architecture | Root README and docs |
| `visitor-journey.svg` | Visitor navigation flow | Root README |
| `artwork-publishing-flow.svg` | Artwork provenance and publishing process | Root README |

## Asset rules

- These SVGs are explanatory diagrams, not screenshots of a running browser.
- Do not label them as product screenshots.
- Keep accessible `title` and `desc` elements.
- Validate SVG/XML syntax before committing.
- Update README and documentation references when files are renamed.
- Keep original gallery artwork under `images/`; do not replace it with these diagrams.
