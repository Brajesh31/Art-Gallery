# 🤝 Code of Conduct

## Our commitment

The Art Gallery project welcomes constructive participation from people with different backgrounds and experience levels. Contributors should treat one another with respect and focus feedback on ideas and evidence rather than individuals.

## Expected behaviour

- Be respectful, patient, and inclusive.
- Explain disagreement constructively.
- Accept technical feedback in good faith.
- Keep discussions relevant to the project.
- Respect copyright, privacy, and ownership of artwork and content.
- Avoid sharing another person's personal information without permission.

## Unacceptable behaviour

Harassment, discrimination, threats, personal attacks, doxxing, intimidation, deliberate disruption, and misuse of private information are not acceptable.

## Scope

This code applies in repository issues, pull requests, code reviews, project discussions, and other spaces where someone is representing or participating in the project.

## Reporting

Report concerns privately through the maintainer route described in [SUPPORT.md](SUPPORT.md). Do not publish personal information or secrets in a public issue.

## Enforcement

The maintainer may remove inappropriate content, issue a warning, restrict participation, or exclude a contributor from project spaces depending on severity and recurrence. Retaliation against good-faith reports is not acceptable.
