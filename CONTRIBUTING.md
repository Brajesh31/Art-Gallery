# Contributing

Create a focused branch, preserve the existing static structure, and keep changes accessible on mobile and desktop. Check all three HTML pages after changing shared CSS or navigation. Do not add build tooling unless the project needs it.

Before opening a pull request, validate links, image paths, responsive behavior, and external CDN loading. Do not commit private files, credentials, generated output, or copyrighted images without permission. Report security concerns through [SECURITY.md](./SECURITY.md).
